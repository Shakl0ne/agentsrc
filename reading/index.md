# Reading · 论文解读与随笔

> 解读与 Agent 工程相关的论文，分享阅读笔记与工程随笔。

「**Reading**」专栏站到更高一层，问的是：**Agent 该怎么做**。我们解读相关方向的论文，读的是研究者的判断、取舍与开放问题——并尝试把纸上结论拉回真实的终端编程场景，看看论文结论和真实世界之间，到底隔了什么。

无论你是想理解「skill 这类结构化知识注入到底什么时候有效」，还是想看看「一次受控实验怎么把'黑盒'的 agent 行为变成可观察的证据」，都能在这里读懂、带走。

## 关于本专栏

- **内容形态**：论文解读（长，带研究设计拆解）+ 随笔 / 阅读笔记（中，偏个人视角）
- **写作视角**：不搬运 abstract，而是「研究者在问什么问题 → 怎么设计实验回答 → 结论的可信边界在哪 → 对工程实践意味着什么」
