# Reading · 论文解读与随笔

> 走出源码逐行，站到更高一层——解读与 Agent 工程相关的论文，分享阅读笔记与工程随笔。

四个源码专栏带你逐行走读 `Claude Code × OpenCode × Codex × DeepSeek Harness` 的实现；这里的「**Reading**」专栏则反过来问：**站在更高一层看 Agent 该怎么做**。我们解读相关方向的论文，读的是研究者的判断、取舍与开放问题——并尝试把它拉回到本站反复拆解的那些终端编程 Agent 上，看看纸上结论和真实实现之间，到底隔了什么。

无论你是想理解「skill 这类结构化知识注入到底什么时候有效」，还是想看看「一次受控实验怎么把'黑盒'的 agent 行为变成可观察的证据」，都能在这里读懂、带走。

## 关于本专栏

- **内容形态**：论文解读（长，带研究设计拆解）+ 随笔 / 阅读笔记（中，偏个人视角）
- **写作视角**：不搬运 abstract，而是「研究者在问什么问题 → 怎么设计实验回答 → 结论的可信边界在哪 → 对工程实现的启示是什么」
- **与源码专栏的关系**：本专栏讨论的机制（如 skill、memory、工具）尽量回连到本站硬件实现（Claude Code 的 SKILL.md、DeepSeek 的 capability 缝等），让「论文」和「实现」互相照亮
- **署名规范**：与源码专栏一致，正文中立叙述，作者统一署 `shaco`
